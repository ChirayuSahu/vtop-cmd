**Description:**

```
VTOP Command makes VIT's VTOP student portal faster and easier to use. Unofficial; not affiliated with VIT.

⌘K COMMAND MENU
Press ⌘K (Ctrl+K on Windows and Linux) on any VTOP page and type where you want to go: "DA", "marks", "timetable", "attendance". Typos are fine, and the pages you use most rise to the top. You can change the shortcut.

THEMES
Light, Dark, OLED and Blue themes for the whole portal, with low-contrast text fixed and status colours kept.

DEFAULT SEMESTER
Pick your semester once. Time Table, Attendance, Marks and other pages that ask for it are filled in when they first open. Registration, payment and similar pages are never touched.

ATTENDANCE AND MARKS
See how many classes you can still miss (or need to attend) to stay at 75%. Each marks table gets a total row showing the marks you've already lost.

PENDING ASSIGNMENTS
Digital Assignment Upload lists each course's unsubmitted work with due dates and countdowns.

CGPA CALCULATOR
Reads your grade history and current courses, then projects your semester GPA and CGPA from the grades you expect.

DOCUMENT VIEWER
PDF, Word and PowerPoint files from VTOP open in a built-in viewer instead of piling up in Downloads. Course materials get separate Preview and Download buttons, and files are saved with their real titles instead of VTOP's coded names.

ALSO
• Searchable dropdowns on long VTOP forms
• Late Hour Request presets that fill your usual answers (you still submit)
• Image CAPTCHA read on your device (you still sign in)

PRIVATE AND READ-ONLY
• Runs only on vtop.vit.ac.in
• Never submits forms, uploads files, registers or pays for you
• Uses only the requests VTOP's own buttons make, one at a time, with results cached
• No analytics, no tracking, no other servers; everything stays in your browser

Open source: https://github.com/ChirayuSahu/vtop-cmd
Website: https://vtop-cmd.chirayusahu.com
```

## Privacy practices tab

**Single purpose:**

> Make VIT's VTOP student portal faster and easier to use: a keyboard command menu, dark mode and study helpers (attendance, marks, assignments, CGPA, documents) added to vtop.vit.ac.in pages.

**Permission justifications:**

| Permission | Justification |
| --- | --- |
| `storage` | Saves the user's settings on their device: theme, default semester, keyboard shortcut, command-menu ranking, form presets and grade predictions. Session storage briefly caches assignment due dates so VTOP isn't asked again. |
| Host permission `https://vtop.vit.ac.in/*` | The extension only works on VIT's VTOP portal. It needs access to add the command menu, dark mode and helpers to VTOP pages, and to load VTOP pages and assignment dashboards with the user's existing session, exactly as VTOP's own buttons do. It runs on no other site. |

**Remote code:** No, I am not using remote code. (Everything, including PDF.js and the document renderers, is bundled in the package; the CSP allows only `'self'` scripts.)

**Data usage** — tick these, and leave every other type unticked:

- **Website content:** the extension reads VTOP pages the user opens (timetable, attendance, marks, assignments) to add its features. This is processed on the device and is not sent anywhere.
- **Personally identifiable information:** the registration number and student ID shown on VTOP are used only as local storage keys (so one student's grade predictions and cached deadlines don't mix with another's). They are not sent anywhere.

Leave unticked: health, financial and payment, authentication information (the password is never read or stored; the CAPTCHA image is read on the device only), personal communications, location, web history, user activity.

**Certify all three:**
- I do not sell or transfer user data to third parties, outside of the approved use cases.
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
- I do not use or transfer user data to determine creditworthiness or for lending purposes.

**Privacy policy URL:** https://vtop-cmd.chirayusahu.com/privacy

## Notes for review

- The name uses "VTOP" because that's the portal it works on; the description says "Unofficial; not affiliated with VIT" in its first lines, and the icon is original. If the listing is rejected for impersonation, the fix is usually to make the "unofficial" wording more prominent, not to rename.
- After it's approved, Chrome and Brave users who loaded the ZIP unpacked should remove that copy and install from the store, so they get automatic updates.
